# T04 · Extracción agrupada y parser completo

Fecha de verificación: 22 de octubre de 2026.

## Resultado verificable

La extracción agrupa las nueve series explícitas de cada una de las 88
geografías, por lo que una ejecución completa espera 792 series. Conserva cada
CSV descargado y un manifiesto JSON atómico bajo `data/raw/<uuid>/`; ambos
quedan fuera de Git. La CLI `inflacion-lab etl fetch` valida todo el lote pero
no escribe observaciones ni marca una publicación D1.

El parser se verificó con las tres exportaciones oficiales congeladas en T02
(México, Jalisco y Guadalajara): mantiene identificador del proveedor, rubro,
`date` mensual y `Decimal`. La prueba no recurre a INEGI en vivo.

## Verificación local

- `make check`: todos los hooks pasaron.
- `make test`: 25 pruebas pasaron; cubren fixtures reales, columnas
  reordenadas o inválidas, claves duplicadas, timeout, HTTP 429, error
  persistente, HTML con HTTP 200 y un lote incompleto de 88 ubicaciones.

## Limitaciones

No se ejecutó una descarga viva: no forma parte de la suite repetible y los
originales completos no se suben al repositorio. T05 reutilizará estas
interfaces para validar y publicar, de manera transaccional, el lote completo.

# T08 · Primera vista nacional

Fecha: 2026-10-26. Entorno: Node 24.17, npm 11, React 19, Vite 7 y ECharts 6.

## Implementación verificada

`web/` consume exclusivamente la API relativa `/api/inflacion/v1`; Vite solo
usa `localhost` en su proxy de desarrollo y la base de publicación se configura
con `VITE_WEB_BASE_PATH` (por defecto `/inflacion/`). La página muestra el
resumen nacional, controles de medida/corte/inicio, gráfica ECharts y una tabla
plegable equivalente. No carga fixtures como respaldo de producción.

El cliente aborta solicitudes anteriores y conserva un identificador de petición
para que una respuesta lenta no sustituya una selección más reciente. Presenta
estados de carga, error y falta de publicación, además de fuente y fecha de
carga. Los controles conservan etiquetas asociadas, foco visible y diseño
apilado para pantalla pequeña.

## Comprobaciones reproducibles

```text
make test-web   # 2 passed
make build-web  # TypeScript y Vite pasan
npm run lint --prefix web  # pasa
```

El build inicial de ECharts mide 452 kB gzip. Vite recomienda fragmentarlo; se
conserva como límite conocido para una entrega posterior, sin ocultar datos ni
alterar la gráfica inicial. NPM reporta tres vulnerabilidades transitivas al
instalar el lockfile; no se aplicó `npm audit fix --force` porque implicaría
actualizaciones rompientes fuera del alcance de T08.

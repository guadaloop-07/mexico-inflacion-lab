# T07 · API de lectura

Fecha: 2026-10-26. Entorno: Python 3.12, FastAPI 0.162, Pydantic 2.14,
Uvicorn 0.54 y PostgreSQL 18 en Compose local (puerto 5433).

## Implementación verificada

La fábrica `inflacion_lab.api.app:create_app` no abre conexiones ni exige
credenciales al importarse. Las rutas bajo `/api/inflacion/v1` son de lectura:
`/catalogo`, `/resumen`, `/series`, `/health/live` y `/health/ready`. `make
api` inicia Uvicorn mediante la fábrica y OpenAPI enumera las rutas con ese
prefijo.

Cada petición a datos abre una transacción PostgreSQL `REPEATABLE READ READ
ONLY`. Catálogo, resumen e historia reutilizan las vistas métricas canónicas;
la historia genera meses ausentes con `estado=no_publicado`, sin interpolarlos.
Las respuestas incluyen versión de la última ejecución exitosa, periodo fuente
máximo, fuente, ETag y `Cache-Control: public, max-age=300`. Una coincidencia
en `If-None-Match` devuelve 304. Los errores de parámetros, geografía/rubro
desconocidos y base/esquema no disponibles no exponen URLs ni trazas internas.

Mientras no exista publicación exitosa, las rutas de negocio responden con
`meta.estado=sin_publicacion`; una selección válida sin observaciones conserva
`sin_datos`. El healthcheck vivo no consulta la base y readiness devuelve 503
sin una configuración o esquema disponible.

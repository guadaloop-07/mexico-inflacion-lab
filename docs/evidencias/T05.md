# T05 · Publicación transaccional

Fecha: 2026-10-25. Entorno: Python 3.12, PostgreSQL 18 en Compose y fuente
primaria [INEGI, exportador del INPC](https://www.inegi.org.mx/app/indicesdepreciosv2/Exportacion.aspx).

## Implementación verificada

`etl run --mode bootstrap|refresh|reconcile` registra una ejecución, obtiene un
bloqueo asesor de PostgreSQL y conserva cada original bajo `data/raw/<uuid>/`.
Después de que las 88 geografías, las 792 series y los meses consecutivos pasan
la validación, publica catálogo, archivos, observaciones, revisiones y estado de
éxito en una sola transacción. Un lote idéntico conserva las observaciones y no
crea revisiones; un valor distinto se audita con valores anterior y nuevo.

La migración `20261025_01` cambia los índices y las revisiones a
`NUMERIC(18,12)`: las exportaciones oficiales congeladas contienen doce
posiciones decimales y no deben redondearse silenciosamente.

## Pruebas reproducibles

```text
pytest -m 'not integration'  # 30 passed
pytest -m integration        # 6 passed
```

La integración usa PostgreSQL real y verifica idempotencia, auditoría de una
corrección, rollback frente a un índice inválido y exclusión de un segundo
escritor. La suite no consulta al INEGI.

## Bootstrap en vivo y límite actual

El 25 de octubre se ejecutó el bootstrap contra el exportador vigente con las
88 geografías y el intervalo 2018–2026. Las 88 respuestas devolvieron HTTP 500;
el manifiesto sanitizado está en
`data/raw/dd462b83-5972-428f-a5da-b01fb987a5d1/manifest.json` fuera de Git.
La ejecución quedó `fallida` y una consulta independiente confirmó cero filas
en `observaciones`, por lo que no se publicó una versión parcial.

D1 sigue pendiente de que el exportador vuelva a aceptar las solicitudes o de
documentar con INEGI un formato de petición actualizado. La carga y la
recuperación quedan verificadas localmente; los originales completos no se
incluyen en el repositorio.
